🖥️ 本地模式 (Local)

開啟 = 連本機後端 127.0.0.1:8000(後端 + DB 都跑在你電腦);關閉 = 連雲端 HuggingFace

⚠️ 本地模式需要你先在終端機(專案根目錄)啟動本地後端:
$env:DB_LOCAL='1'; python -m uvicorn api.main:app --reload --port 8000
後端 + 資料庫 (SQLite, api/auth.db) 都會跑在本機、不連雲端。本地 DB 是全新空的,第一次請註冊一個 email/密碼帳號。
❗ 這個頁面也要用 http 開(本機 / Live Server),不能在 https 的 GitHub Pages 上用本地模式 —— HTTPS 頁面無法呼叫 http 的本機後端,瀏覽器會擋(Failed to fetch)。
※ 用 127.0.0.1 而非 localhost:Windows 上 localhost 常被解析成 IPv6,但後端只聽 IPv4 → 也會 Failed to fetch。
