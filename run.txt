================================================================================
                    I2AI AutoML 項目 - 本地測試指南
================================================================================

【環境要求】
- Python 3.8 以上（建議 3.9+）
- pip 或 conda
- Windows/macOS/Linux

================================================================================
【第一步】環境設置
================================================================================

# 1.1 創建虛擬環境（推薦）
python -m venv venv

# 1.2 激活虛擬環境
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# 1.3 升級 pip
python -m pip install --upgrade pip

================================================================================
【第二步】數據收集（可選）
================================================================================

# 2.1 收集 OpenML 數據集
python -m pip install openml pandas tqdm
python data_collect.py

# 2.2 收集時序數據集
python -m pip install aeon pandas tqdm
python data_collect_time.py

# 預期結果：下載的數據將存放在 Dataset/ 目錄下

================================================================================
【第三步】後端服務啟動
================================================================================

# 3.1 安裝後端依賴
python -m pip install -r api/requirements.txt

# 3.2 啟動 FastAPI 服務器 (終端 1)
python -m uvicorn api.main:app --reload --port 8000

# 服務器已運行：
# - API 主頁：http://127.0.0.1:8000/
# - Swagger 文檔：http://127.0.0.1:8000/docs
# - ReDoc 文檔：http://127.0.0.1:8000/redoc
# 線上版本：https://i2ai-automl-api.onrender.com

================================================================================
【第四步】前端啟動
================================================================================

# 4.1 啟動本地 HTTP 服務器 (終端 2)
python -m http.server 5500

# 4.2 訪問前端
# - 打開瀏覽器：http://localhost:5500
# - 選擇 index.html 文件

================================================================================
【測試流程】
================================================================================

測試用例 1 - 完整工作流程：
  1. 訪問 http://localhost:5500 (前端)
  2. 上傳 CSV 文件（或使用預置數據）
  3. 進行數據預處理和審計
  4. 訓練機器學習模型
  5. 查看可視化結果（特徵重要性、SHAP 解釋等）

測試用例 2 - 後端 API 直接測試：
  1. 訪問 http://127.0.0.1:8000/docs
  2. 展開各端點查看參數說明
  3. 使用 Swagger UI 直接測試 API

測試用例 3 - 本地數據測試：
  1. 執行 data_collect.py 下載數據
  2. 前端上傳下載的 CSV 文件
  3. 完整執行工作流程

================================================================================
【常見命令速查表】
================================================================================

# 安裝所有依賴（後端 + 數據收集）
python -m pip install -r api/requirements.txt openml aeon pandas tqdm shap plotly

# 同時啟動後端和前端（需要 2 個終端）
# 終端 1:
python -m uvicorn api.main:app --reload --port 8000
# 終端 2:
python -m http.server 5500

# 運行測試（如果有 tests 目錄）
python -m pytest api/visualize/tests/

# 查看 API 文檔
# - Swagger: http://127.0.0.1:8000/docs
# - ReDoc: http://127.0.0.1:8000/redoc

================================================================================
【故障排查】
================================================================================

問題 1：ModuleNotFoundError: No module named 'fastapi'
解決：python -m pip install -r api/requirements.txt

問題 2：Port 8000 已被佔用
解決：python -m uvicorn api.main:app --reload --port 8001

問題 3：前端無法連接後端
解決：確認後端服務已啟動、檢查防火牆設定、確保 CORS 已配置

問題 4：數據集下載失敗
解決：檢查網路連接、手動下載數據到 Dataset/ 目錄、或使用本地 CSV 文件
